# Everything Claude Code reads, in one tree

The sidebar lists skills, commands, subagents, hooks, MCP servers, plugins, settings and memory from four levels, highest precedence first:

- **System**: policy an administrator or your organization deployed
- **User**: `~/.claude`, applies to every project
- **Plugins**: what your installed plugins contribute
- **Workspace**: the `.claude` folder of the project you opened

Click any row to open the file it comes from. Greyed rows show surfaces you are not using yet, and where they would live.

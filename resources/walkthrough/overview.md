# See the whole picture

The **Overview** page answers the questions a tree cannot:

- **Context budget**: roughly how many tokens of configuration load before your first prompt, and which files are the largest
- **Effective settings**: the values a session in this project really uses after all settings files are merged, and which file each one comes from
- **Hook timeline**: which hooks run on which event, in lifecycle order
- **Overrides**: what shadows what

Pick a project at the top when more than one folder is open.
